CARA MEMASANG APLIKASI DI LAPTOP:
----------------------------------------------------------------
1. Ekstrak file ZIP ini ke folder pilihan Anda (misal: di Dokumen / D:).
2. Dobel-klik file: "Pasang_Di_Laptop_Guru.bat".
3. Pintasan berlogo resmi "DASHBOARD LAPORAN SDN KALISALAK 01" 
   akan langsung muncul di layar Desktop Anda.

----------------------------------------------------------------
CARA MEMBUKA APLIKASI:
----------------------------------------------------------------
1. Buka icon berlogo resmi Kabupaten Tegal di Desktop Anda:
   "DASHBOARD LAPORAN SDN KALISALAK 01".
2. Di dalam jendela aplikasi, klik tombol hijau besar:
   "🚀 MASUK DASHBOARD LAPORAN".
3. Browser Anda akan langsung terbuka secara resmi dan aman.
